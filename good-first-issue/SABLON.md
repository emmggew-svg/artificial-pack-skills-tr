# Good First Issue Şablonu

Yeni başlayanlar için issue açarken bu şablonu kullanın.

## Başlık

`[good-first-issue] <tek skill adı veya tek görev>`

## Kapsam (Scope)

- Tek skill: `skills/<skill-adi-tr>/`
- Bu issue dışında başka dosyaya dokunmayın.

## Görev

- [ ] Ne yapılacak (1-2 cümle):
- [ ] Örnek girdi / beklenen çıktı:

## Kabul Kriteri

- [ ] `SKILL.md` güncellendi / eklendi
- [ ] `npm run lint:skills` yeşil
- [ ] Örnek kullanım eklendi

## Test Şartı

- `npm run lint:skills` çıktısını issue/PR yorumuna yapıştırın.
- Kırmızıysa draft PR açıp log'u ekleyin.
